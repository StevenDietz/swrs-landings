Copies as a clickable image. Pasting into Outlook keeps the link.

Watch the welcome (29 seconds)  ·  Log in to the Client Portal

How to use it

  1. Click Copy for Outlook.
  2. In Outlook, place the cursor and press Ctrl + V.
  3. The image lands as a clickable link.

Blocked button? Use Select it instead, then Ctrl + C. Paste with Ctrl + V, never Paste Special → Picture — that strips the hyperlink. Recipients with images blocked see the alt text and the text links, so the message still lands.
